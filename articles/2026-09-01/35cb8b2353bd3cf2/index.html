Anthropic公式、Claude Codeプラグインのキュレーション済みディレクトリを公開

公式github.com2026.09.01

「claude-plugins-official」はClaude Code向けプラグインの公式キュレーション済みディレクトリです。Anthropicチームが開発・保守する/pluginsディレクトリの「内部プラグイン」と、パートナー・コミュニティ提供で品質・セキュリティ基準を満たした/external_pluginsディレクトリの「外部プラグイン」の2種類で構成されます。

「/plugin install {プラグイン名}@claude-plugins-official」コマンドや、Claude Codeの「/plugin > Discover」からインストールできます。プラグインの標準構造には.claude-plugin/plugin.json(必須)やcommands/、agents/、skills/などが含まれ、一度公開した「name」フィールドは変更できない仕様です。なお、Anthropicはプラグインの内容自体は検証していないため、利用者側での信頼性確認が必要と注意書きがあります。

出典が伝えている要点

  • リポジトリ名は「anthropics/claude-plugins-official」である。
  • Claude Code用プラグインの公式キュレーション済みディレクトリとされている。
  • プラグインは/pluginsディレクトリの「内部プラグイン」と/external_pluginsディレクトリの「外部プラグイン」の2種類に分かれる。
  • 内部プラグインはAnthropicチームによって開発・保守される。
  • 外部プラグインはパートナーとコミュニティから提供され、品質・セキュリティ基準を満たす必要がある。
  • プラグインは「/plugin install {プラグイン名}@claude-plugins-official」というコマンドでインストールできる。
  • Claude Codeの「/plugin > Discover」からもプラグインを検索・インストールできる。
  • プラグインの標準構造には.claude-plugin/plugin.json(必須)、.mcp.json、commands/、agents/、skills/、README.mdが含まれる。
  • 一度公開されたプラグインの「name」フィールドは変更できない仕様である。
  • UI表示名を変更したい場合は「displayName」フィールドを使用する。
  • 複数のスキル(SKILL.md)を一つのプラグインでバンドルする「スキルバンドルプラグイン」が可能である。
  • Anthropicはプラグインの内容を検証していないため、利用者は信頼できることを確認する必要があるとの注意書きがある。
