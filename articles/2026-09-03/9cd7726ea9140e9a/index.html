Anthropic公式、Claude Codeプラグイン集

公式github.com2026.09.03

Anthropicが管理する、Claude CoworkおよびClaude Code向けのコミュニティ貢献プラグインのマーケットプレイスです。リポジトリ内の.claude-plugin/marketplace.jsonにプラグイン一覧が掲載されており、これはAnthropicの内部レビューパイプラインから毎晩同期される読み取り専用ミラーで、セキュリティスキャンに合格し配布承認されたプラグインのみが掲載されます。

Claude Coworkでは https://claude.com/plugins/ から直接インストールでき、Claude Codeではclaude plugin marketplace add anthropics/claude-plugins-communityでマーケットプレイスを追加後、claude plugin install <plugin-name>@claude-communityでインストールできます。プラグインの提出は専用サイト（clau.de/plugin-directory-submission）から行う仕組みで、このリポジトリに直接開かれたプルリクエストは自動的にクローズされます。関連リポジトリとして、Anthropic公式プラグイン集のanthropics/claude-plugins-officialや、職務別知識作業プラグイン集のanthropics/knowledge-work-pluginsもあります。

出典が伝えている要点

  • リポジトリはAnthropicが管理している
  • リポジトリはClaude CoworkおよびClaude Code用のコミュニティ貢献プラグインのマーケットプレイスである
  • リポジトリ内の.claude-plugin/marketplace.jsonファイルにコミュニティプラグインの一覧が掲載されている
  • marketplace.jsonはAnthropicの内部レビューパイプラインから毎晩更新される読み取り専用ミラーである
  • 掲載されるのはセキュリティスキャンに合格し配布承認されたプラグインのみである
  • Claude Coworkではhttps://claude.com/plugins/から直接プラグインをインストールできる
  • Claude Codeでは「claude plugin marketplace add anthropics/claude-plugins-community」でマーケットプレイスを追加できる
  • Claude Codeでは「claude plugin install <plugin-name>@claude-community」でプラグインをインストールできる
  • プラグインの提出はclau.de/plugin-directory-submissionという公式サイトから行う必要がある
  • このリポジトリに直接開かれたプルリクエストは自動的にクローズされる
  • 関連リポジトリとしてanthropics/claude-plugins-official(Anthropic公式プラグイン)とanthropics/knowledge-work-plugins(職務別知識作業プラグイン)がある
