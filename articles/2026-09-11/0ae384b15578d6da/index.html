Google公式Goクライアントライブラリ、「完成・メンテナンスモード」を明言

公式github.com2026.09.11

Googleが公式に提供する、Google Discovery Serviceの記述から自動生成されたGo言語向けクライアントライブラリ集です。多数のGoogle APIにGoからアクセスするためのパッケージ群を提供しますが、「完成しておりメンテナンスモード（重大な不具合やセキュリティ脆弱性への対応は行うが新機能追加はしない状態）にある」と説明されています。

DatastoreやPub/SubなどのGoogle Cloud Platform APIについては、このライブラリではなく別の「Cloud Client Libraries for Go」の利用が推奨されています。認証はGoogleのApplication Default Credentialsをデフォルトとしつつ、サービスアカウントキーやOAuth2トークンなど複数の方式に対応しています。スター数4.5k、フォーク数1.4k、コミット数3,680を数え、BSD-3-Clauseライセンスで公開されています。

出典が伝えている要点

  • このリポジトリはGoogle Discovery ServiceのJSON記述ファイルから自動生成されたGo向けクライアントライブラリ集である
  • このライブラリ群はGoogleによって公式にサポートされている
  • ライブラリは「完成している」とみなされ「メンテナンスモード」にあるとされている
  • メンテナンスチームは重大な不具合とセキュリティ脆弱性への対応を行うが、新機能追加は行わない
  • DatastoreやPub/SubなどのGoogle Cloud Platform APIについては、このライブラリではなく「Cloud Client Libraries for Go」の使用が推奨されている
  • リポジトリの主要言語はGoである
  • リポジトリはBSD-3-Clauseライセンスで公開されている
  • リポジトリのスター数は4.5k、フォーク数は1.4k、コミット数は3,680である
  • ライブラリはデフォルトでGoogleのApplication Default Credentialsを使用する認証をサポートし、サービスアカウントキーやOAuth2トークンなど複数の認証方式に対応している

原文より

These client libraries are officially supported by Google. However, the libraries are considered complete and are in maintenance mode.
If you're working with Google Cloud Platform APIs such as Datastore or Pub/Sub, please use the Cloud Client Libraries for Go instead.
