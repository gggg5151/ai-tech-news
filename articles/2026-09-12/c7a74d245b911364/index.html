GitHub公式、仕様駆動開発ツール「Spec Kit」

公式github.com2026.09.12

GitHubが公開するオープンソースのツールキットで、コードではなく仕様を起点にAIコーディングエージェントで実装を生成する「仕様駆動開発（Spec-Driven Development）」を実践します。Constitution→Specify→Plan→Tasks→Implement→Convergeという開発フローに沿って、/speckit.*コマンドを呼び出しながら進めます。

GitHub Copilot、Claude、Codex CLIなど30以上のAIコーディングエージェントに対応し、プロジェクト固有のオーバーライド・プリセット・エクステンションという3層のカスタマイズ構造や、役割別の完全なセットアップを一度に導入できる「バンドル」機能も備えています。uvツールでインストールでき、MITライセンスで公開されています。

出典が伝えている要点

  • Spec KitはGitHubが公開しているオープンソースのツールキットである。
  • Spec Kitは「仕様駆動開発(Spec-Driven Development)」を実践するためのツールである。
  • このアプローチでは仕様が実行可能な指標となり、直接実装を生成するとされている。
  • コア開発フローはConstitution、Specify、Plan、Tasks、Implement、Convergeの各ステップで構成される。
  • 拡張機能としてバグ修正ワークフローとアイデア評価の仕組みが用意されている。
  • 30以上のAIコーディングエージェントに対応しており、GitHub Copilot、Claude、Codex CLIなどが含まれる。
  • インストールにはuvツールを使い、'uv tool install specify-cli --from git+https://github.com/github/spec-kit.git'のようなコマンドで導入する。
  • 動作環境としてLinux/macOS/Windows、Python 3.11以上、Git、uvまたはpipxが必要とされている。
  • MITライセンスで公開されている。
  • カスタマイズはプロジェクト固有のオーバーライド、プリセット、エクステンションの3層の優先度構造を持つ。
  • 役割別の完全なセットアップを一度にインストールできる「バンドル」機能がある。
