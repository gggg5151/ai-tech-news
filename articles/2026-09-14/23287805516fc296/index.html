TailscaleのAIゲートウェイ「Aperture」正式リリース

報道publickey1.jp2026.09.14

Tailscaleが、AIゲートウェイサービス「Aperture」を正式リリースしました（8月26日に発表）。VPN内でAIサービスをAPIキーの配布なしに統合でき、コスト管理・ガードレール・監査ログの各機能に加え、MCP(Model Context Protocol、AIとツールをつなぐ標準規格)のプロキシ機能を備え、AIモデル用のトークンを購入・管理することもできます。

今回新たに「Tailscale MCP」と「Tailscale SSH MCP」が追加され、AIエージェント自身がTailscaleネットワーク上でのノード追加やSSH接続を実行できるようになりました。ただし新規マシンノードの追加には人間の承認が必須とされ、既存のアクセス制御設定は維持されるうえ、すべての操作は監査ログに記録される仕組みです。

出典が伝えている要点

  • Tailscaleが「Aperture」というAIゲートウェイサービスを正式リリースした
  • Apertureは2026年8月26日にTwitterで発表された
  • ApertureはVPN内でAIサービスを統合でき、APIキーの配布が不要である
  • Apertureはコスト管理・ガードレール・監査ログの各機能を備える
  • ApertureはMCP(Model Context Protocol)のプロキシ機能を持つ
  • Aperture内でAIモデル用のトークンを購入・管理できる
  • 新たに「Tailscale MCP」と「Tailscale SSH MCP」が追加された
  • この新機能によりAIエージェントがTailscaleネットワーク内でのノード追加やSSH接続を実行できるようになった
  • 新規マシンノードの追加には人間による承認が必須とされている
  • AIエージェントによる操作はすべて監査ログに記録される
  • 既存のアクセス制御設定はAIエージェントの操作後も維持される
