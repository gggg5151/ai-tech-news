Claude Code公式リポジトリ

公式github.com2026.09.17

Anthropic公式のGitHubリポジトリ「claude-code」です。ターミナルに統合されたエージェント型のコーディングツールで、コードベースの理解、自然言語コマンドによる日常的なコーディングタスクの実行、Gitワークフローの処理などを行えます。プロジェクトディレクトリでclaudeコマンドを実行して使用し、インストールはcurlスクリプト、Homebrew、WinGet、npm(非推奨)など複数の方法があります。Node.js 18以上が動作要件です。

使用データや会話データ、フィードバックは収集されますが、モデルの訓練には使用されないとされています。

出典が伝えている要点

  • Claude Codeはターミナルに統合されたエージェント型のコーディングツールである
  • Claude Codeはコードベースを理解できる
  • Claude Codeは自然言語コマンドを通じて日常的なコーディングタスクを実行できる
  • Claude CodeはGitワークフローを処理できる
  • MacOS/Linuxではcurlコマンドでインストールスクリプト（https://claude.ai/install.sh）を実行してインストールできる
  • Windowsではpowershellでinstall.ps1を実行してインストールできる
  • Homebrewでは「brew install --cask claude-code」でインストール可能
  • WinGetでは「winget install Anthropic.ClaudeCode」でインストール可能
  • npmでは「npm install -g @anthropic-ai/claude-code」でインストール可能だが非推奨とされている
  • プロジェクトディレクトリで「claude」コマンドを実行して使用する
  • Node.js 18以上が動作要件である
  • 使用データ（受理/拒否）、会話データ、フィードバックが収集されるが、モデル訓練には使用されない
