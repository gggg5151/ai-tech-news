Claude CodeのAGENTS.md、初回セッションは未読み込み

体験談qiita.com2026.09.21

Claude Code 2.1.277のchangelogには「CLAUDE.mdが存在しないプロジェクトでは、Claude CodeがAGENTS.mdを読む」という機能追加が記載されています。しかし既存の日本語解説記事の一部には「読まない」と書かれているものもあり、筆者(@suwa_nobu氏、株式会社JQIT所属)はこの食い違いを実測で検証しました。

検証方法は、各設定ファイル(AGENTS.md、CLAUDE.md、CLAUDE.local.md)に一意の合言葉を埋め込み、ファイル読み取りツールを全て禁止した状態でAIに「指示にある合言葉を全部挙げよ」と指示するというものです。Windows 10環境にClaude Code 2.1.277を隔離導入して試した結果、AGENTS.mdのみが存在する場合はその内容が読まれる一方、CLAUDE.mdやCLAUDE.local.mdが存在するとそちらが優先され、AGENTS.mdは読まれないことが分かりました。

さらに公式情報として、AGENTS.mdサポートを含むバージョンへのインストール・アップグレード後の最初のセッションではAGENTS.mdは読まれず、次のセッションから読まれるという制約があることも判明しました。CLAUDE.local.mdを個人用の未コミット指示として置くプロジェクトでは、AGENTS.mdが警告なく無効化されてしまう「落とし穴」がある点も指摘されています。

出典が伝えている要点

  • Claude Code 2.1.277のchangelogに「CLAUDE.mdが存在しないプロジェクトではClaude CodeがAGENTS.mdを読む」という機能追加が記載されている
  • 既存の日本語解説記事の一部には「(Claude CodeはAGENTS.mdを)読まない」と記載されているものがある
  • 筆者は各設定ファイル(AGENTS.md、CLAUDE.md、CLAUDE.local.md)に一意の合言葉(パスフレーズ)を埋め込む方法で検証を行った
  • 検証ではファイル読み取りツールを全て禁止し、AIに『指示にある合言葉を全部挙げよ』と指示する手法を用いた
  • 検証はWindows 10環境にClaude Code 2.1.277を隔離導入して行われた
  • AGENTS.mdのみが存在する場合、AGENTS.mdの内容は読まれる
  • AGENTS.mdとCLAUDE.mdが両方存在する場合、CLAUDE.mdのみが読まれる
  • AGENTS.mdとCLAUDE.local.mdが両方存在する場合、CLAUDE.local.mdのみが読まれる
  • Claude Codoの公式情報として『AGENTS.mdサポートを含むバージョンへのインストール・アップグレード後、最初のセッションではAGENTS.mdは読まれず、次のセッションから読まれる』という記述がある
  • Claude Codeの公式情報として『CLAUDE.local.mdもカウントされるため、AGENTS.mdに依存するプロジェクトで自分専用の未コミット指示を保持するためにCLAUDE.local.mdを追加すると、AGENTS.mdが読まれなくなる』という記述がある
  • 記事の公開日は2026年9月19日である
  • 筆者は株式会社JQITに所属する@suwa_nobuというアカウント名で記事を書いている
