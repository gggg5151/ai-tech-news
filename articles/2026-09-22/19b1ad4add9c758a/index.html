MCP公式Go SDK、非推奨機能も12ヶ月はサポート継続

公式github.com2026.09.22

Model Context Protocol（MCP）の公式Go SDKが、Googleと共同でメンテナンスされています。mcp・jsonrpc・auth・oauthexという複数のパッケージで構成され、mcpパッケージがMCPクライアントとサーバーを構築するための主要APIを提供します。

SDK v1.7.0以降は最新のMCP仕様（2026-07-28）を含む直近4つの仕様バージョンをサポート。この最新仕様ではroots・sampling・loggingの各機能が非推奨となりましたが、「互換性維持のため少なくとも12ヶ月間サポートを継続する」としています。GitHub上で5.1kスター、544フォークを獲得しており、新規貢献はApache 2.0、既存コードはMITというデュアルライセンスを採用しています。

出典が伝えている要点

  • このリポジトリはModel Context Protocol(MCP)の公式Go SDKである
  • GoogleとModel Context Protocol側が共同でメンテナンスしている
  • SDKは mcp・jsonrpc・auth・oauthex という複数のインポート可能なパッケージで構成される
  • mcpパッケージはMCPクライアントとサーバーを構築するための主要APIを提供する
  • SDK v1.7.0以降は最新のMCP仕様(2026-07-28)を含む直近4つの仕様バージョンをサポートする
  • SDK v1.0.0からv1.1.0までは2024-11-05までの仕様をサポートする
  • プロトコル2026-07-28においてroots・sampling・loggingの各機能が非推奨(deprecated)となった
  • README記載によれば、SDKは互換性維持のため非推奨機能を少なくとも12ヶ月間サポートし続ける
  • リポジトリはGitHub上で5.1kのスターと544のフォークを獲得している
  • リポジトリのmainブランチには808件のコミットがある
  • リポジトリには54件のオープンイシューと49件のオープンなプルリクエストがある
  • プロジェクトは新規コントリビューションをApache 2.0ライセンス、既存コードをMITライセンスとするデュアルライセンス方式を採用している
