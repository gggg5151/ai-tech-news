グラフィックデザインAI、ユーザー経験から手続記憶を進化

公式arxiv.org2026.09.22

論文「Designer-RSI: Evolving Procedural Memory from User Traffic for Agentic Graphic Design」は、Hongyang Du氏ら4名による研究です。グラフィックデザインは複数の相互依存アクションから編集可能な成果物を作る長期的なエージェントタスクだとし、追加学習なしのフロンティアモデルが230以上のツールを通じてプロフェッショナルデザインソフトウェアを操作しながら、自然言語による「手続記憶」を蓄積・改善するフレームワークを提案しています。

未カバーの小課題には新しい手順を獲得し（拡張）、成功・失敗の実行結果に応じて既存手順を改訂します（深化）。既知の成功パターンが後退しないよう、失敗の修復のみを許可する「マッチドリプレイゲート」という仕組みも導入しています。5ラウンドの実施で手続記憶の数は76から139へ拡張し、GenEval2における実行成功率は72.7%から99.3%へ向上、複数のベンチマークで61.8%〜67.6%の勝率を達成したと報告されています。

出典が伝えている要点

  • 論文タイトルは「Designer-RSI: Evolving Procedural Memory from User Traffic for Agentic Graphic Design」である。
  • 著者はHongyang Du、Lan Yan、Christian Flores、Asim Kadavの4名である。
  • 研究では凍結された（追加学習なしの）フロンティアモデルが230以上のツールを通じてプロフェッショナルデザインソフトウェアを操作する。
  • 提案フレームワークは自然言語スキルによる「外部手続記憶」を用いる。
  • 手続記憶はユーザー経験から設計手順を蓄積・精緻化する。
  • 未カバーの小課題に対しては新しい手順を獲得する（拡張と呼ぶ）。
  • 成功・失敗の実行結果に対して既存手順を改訂する（深化と呼ぶ）。
  • 「マッチドリプレイゲート」という仕組みは失敗修復のみを許可する。
  • マッチドリプレイゲートは既知の成功パターンの後退（劣化）を防ぐためのものである。
  • 研究の目的は検証不可能なフィードバックの下でエージェントの継続的適応を実現することである。
  • 5ラウンドの実施で手続記憶の数が76から139へ拡張した。
  • GenEval2における実行成功率が72.7%から99.3%へ向上し、複数のベンチマークで61.8%〜67.6%の勝率を達成した。
