git diffから関連テストだけ抽出するCLI「jev-test-filter」

体験談zenn.dev2026.09.22

mizchi氏が、今日話題のAI「Jev」を応用したCLIツール「jev-test-filter」を公開しました。git diffの変更内容から実際に影響を受ける可能性の高いテストだけを自動抽出し、vitest、jest、node:test、Playwright、cargo test、go testなど各種テストランナーが解釈できるフィルタ引数として出力します。precommit hook（コミット直前に自動実行される仕組み）での活用を想定しています。

背景にあるのは、Jevが「1つのstateに対して複数の質問を1リクエストで投げられる」という特性です。これをgit diff（state）とテスト群（質問群）の組み合わせに応用しました。使用例はjev-test-filter --base main --exec -- vitest runという一行です。Playwrightプロジェクトでの実例では、割引計算関数の変更に対し7件中1件の関連テストを正しく選別できたとしています。110件のテストを1リクエストで処理してもコストは約0.15円、実行時間は1.3秒だったと報告されています。

出典が伝えている要点

  • ツール名は「jev-test-filter」である
  • 作者はmizchi氏である
  • jev-test-filterはgit diffの変更から影響を受けるテストのみを自動抽出するツールである
  • 抽出結果はテストランナーが解釈できるフィルタ引数として出力される
  • 対応するテストランナーはvitest、jest、node:test、Playwright、cargo test、go testである
  • テストとコード変更の関連性判定にAIを利用している
  • precommit hookでの使用を想定している
  • 使用例のコマンドは「jev-test-filter --base main --exec -- vitest run」である
  • Playwrightプロジェクトで割引計算関数を変更した際、7件中1件の関連テストを正確に選別できたとされている
  • 110件のテストを1リクエストで処理でき、コストは約0.15円だったとされている
  • その処理の実行時間は1.3秒、入力トークン数は23,423であったとされている
  • 背景として、jevには1つのstateに対して複数の質問を1リクエストで投げられる特性があるとされている
