GPT-6 Sol/Luna、API価格50%引き下げ

体験談openai.com2026.09.23

OpenAIの発表によると、新モデル「GPT-6 Sol」と「GPT-6 Luna」が登場しました。今月初めに発表された「GPT-6 Astra」と同様の訓練方法で開発されており、API価格は前世代比で50%引き下げられたとしています。

同社によれば、Solは入力価格が100万トークンあたり4ドルから2ドルへ、出力が20ドルから10ドルへ。Lunaは入力0.20ドルから0.10ドルへ、出力1.20ドルから0.50ドルへとそれぞれ変更されました。プロンプトキャッシュの改善により、キャッシュ済み入力トークンの読み取りには90%の割引が適用されるとのことです。

GitHub Copilotへの統合でも改善が報告されており、同社の計測では数十億リクエスト中で新規処理トークンが50%以上削減されたとしています。ベンチマークではSolがAutomationBenchで33.2%（タスク当たりコスト0.27ドル）、DeepSWE v1.1でSolが68.8%、Lunaが66.6%のスコアを記録したと発表されています。

出典が伝えている要点

  • GPT-6 SolとLunaは、GPT-6 Astraと同様の訓練方法で開発された
  • GPT-6 Astraは今月初めに発表された
  • 新モデルは前世代比でAPI価格が50%低下した
  • プロンプトキャッシュの改善により、キャッシュ済み入力トークンの読み取りに90%の割引が適用される
  • GitHub Copilotでの複数の改善により、数十億リクエスト中で新規処理トークンが50%以上削減された
  • Sol の API価格は入力$4→$2、出力$20→$10に変更された
  • Luna の API価格は入力$0.20→$0.10、出力$1.20→$0.50に変更された
  • AutomationBenchにおいてSolは33.2%のスコアを記録し、タスク当たりのコストは$0.27だった
  • DeepSWE v1.1においてSolは68.8%、Lunaは66.6%のスコアを記録した

原文より

合理化されたコミュニケーションで、より明確さを備え、不要な技術用語や曖昧な表現を削減している
