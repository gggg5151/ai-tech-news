Anthropic公式、金融業界向けClaudeエージェント集

公式github.com2026.09.23

Anthropicが公開したリポジトリ「financial-services」は、投資銀行・株式調査・プライベートエクイティ・ウェルスマネジメントなど金融業務向けのClaudeエージェント、スキル、データコネクタの参考実装集です。提案資料作成の「Pitch Agent」、企業価値評価や財務モデル（DCF・LBOなど）をExcelで実装する「Model Builder」、オンボーディング書類を解析する「KYC Screener」など11個の名前付きエージェントが含まれます。

7つの業種別プラグインバンドルと、Daloopa・Morningstar・S&P Global・FactSet・Moody'sなど11個のMCP（外部データ連携の標準規格）コネクタも収録。Coworkプラグイン、Claude Code CLI、Managed Agents APIの3種類でデプロイできます。Apache 2.0ライセンスで公開されており、「本リポジトリの内容は投資、法律、税務、会計アドバイスではありません」として、すべての出力に有資格専門家によるレビューを必須としています。

出典が伝えている要点

  • リポジトリ名は anthropics/financial-services で、金融サービス業界向けのAIエージェント・スキル・データコネクタの参考実装を提供する
  • 対象ワークフローは投資銀行、株式調査、プライベートエクイティ、ウェルスマネジメントを含む
  • 11個の名前付きエージェントが含まれる
  • エージェントの例としてPitch Agent（提案資料作成）、Meeting Prep Agent（クライアント会議前ブリーフィング）が挙げられている
  • エージェントの例としてMarket Researcher、Earnings Reviewer、Model Builder（DCF・LBO・3ステートメント・コンプスをExcelで実装）が挙げられている
  • エージェントの例としてValuation Reviewer、GL Reconciler、Month-End Closer、Statement Auditorが挙げられている
  • エージェントの例としてKYC Screener（オンボーディング書類解析・ルールエンジン実行）が挙げられている
  • 7個の業種別（垂直）プラグインバンドルが含まれ、financial-analysisがコアとして11個のデータコネクタを共有する
  • 11個のMCPデータコネクタが含まれ、Daloopa、Morningstar、S&P Global、FactSet、Moody's、LSEG、PitchBook、Egnyte、Boxなどと連携する
  • Coworkプラグイン、Claude Code CLI、Managed Agents APIの3種類の利用方法が提供されている
  • リポジトリはApache 2.0ライセンスで提供されている
  • 内容は投資・法律・税務・会計アドバイスではなく、すべての出力は有資格専門家による人間の審査が必須とされている

原文より

本リポジトリの内容は投資、法律、税務、会計アドバイスではありません。アナリスト業務の下書きを生成するツールであり、すべての出力は有資格専門家による人間の審査が必須です。
