Claude Code、AGENTS.mdに対応　CLAUDE.md不在時は自動読み込み

報道publickey1.jp2026.09.24

Anthropicは2026年9月18日、Claude Codeをバージョン2.1.277に更新し、AIコーディングアシスタント向け共通指示書フォーマット「AGENTS.md」（開発環境情報やテスト手順、PRガイドラインなどを記載するMarkdown形式のファイル）への対応を追加しました。CLAUDE.mdが存在しないプロジェクトでは、Claude Codeが代わりにAGENTS.mdを自動的に読み込みます。

OpenAI Codex、Google Gemini CLI、Devin、Cursor、GitHub Copilotなど主要なAIコーディングツールは既に対応済みで、今回の対応により異なるベンダー間での設定共有・移行がしやすくなると見込まれます。なお、Amazon Bedrock、Google Vertex AI、Microsoft Foundry経由の利用では今回はまだ対応していません。

出典が伝えている要点

  • Anthropicは2026年9月18日にClaude Codeをバージョン2.1.277に更新した
  • このアップデートでClaude CodeがAGENTS.mdファイルのサポートを追加した
  • CLAUDE.mdが存在しないプロジェクトでは、Claude CodeはAGENTS.mdを自動的に読み込む
  • AGENTS.mdはAIコーディングアシスタント向けのMarkdown形式の指示書である
  • AGENTS.mdには開発環境情報、テスト手順、PRガイドラインなどを記載できる
  • OpenAI CodexはAGENTS.mdに既に対応していた
  • Google Gemini CLIはAGENTS.mdに既に対応していた
  • DevinはAGENTS.mdに既に対応していた
  • CursorはAGENTS.mdに既に対応していた
  • GitHub CopilotはAGENTS.mdに既に対応していた
  • Amazon Bedrock経由の利用ではAGENTS.md対応はまだ実装されていない（not yet on Bedrock, Vertex or Foundryとの記載）
  • Google Vertex AIおよびMicrosoft Foundry経由の利用でもAGENTS.md対応はまだ実装されていない
