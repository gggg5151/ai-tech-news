Vault代替のシークレット管理「OpenBao」

公式github.com2026.09.26

OpenBaoは、シークレット・証明書・鍵などの機密データを安全に管理・保存・配布するためのオープンソースソフトウェアです。任意のキー/値の暗号化保存に加え、AWSやSQLデータベース向けの動的シークレット生成、保存せずにデータを暗号化・復号化する機能、リースによる自動失効管理、シークレットの無効化といった機能を備えています。

MPL-2.0（Mozilla Public License 2.0）ライセンスで提供され、GitHub上で7.7kスターを獲得しています。特定企業ではなく、オープンガバナンスの原則に基づくコミュニティが主導する独立プロジェクトとして運営されることを意図しています。

出典が伝えている要点

  • OpenBaoはシークレット・証明書・鍵などの機密データを管理・保存・配布するためのソフトウェアソリューションである
  • OpenBaoは任意のキー/値シークレットを暗号化して安全に保存する機能を持つ
  • OpenBaoはAWSやSQLデータベースなどのシステム向けに動的シークレットをオンデマンドで生成できる
  • OpenBaoは保存せずにデータを暗号化・復号化する機能（データ暗号化)を持つ
  • OpenBaoは全シークレットにリース期限を設定し、自動的に失効させるリース管理・更新機能を持つ
  • OpenBaoは単一または複数のシークレットを無効化する機能を持つ
  • OpenBaoはMPL-2.0（Mozilla Public License 2.0）ライセンスで提供されている
  • OpenBaoはGitHub上で7.7kのスターを獲得している
  • OpenBaoはOSI承認のオープンソースライセンスの下、オープンガバナンスの原則で運営されるコミュニティ主導のプロジェクトとして提供されることを意図している

原文より

OpenBao is a software solution to manage, store, and distribute sensitive data including secrets, certificates, and keys.
the OpenBao community intends to provide this software under an OSI-approved open-source license, led by a community run under open-governance principles.
