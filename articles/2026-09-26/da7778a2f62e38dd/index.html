Gitに組み込まれた分散バグトラッカー「git-bug」

報道github.com2026.09.26

git-bugは、Gitリポジトリに完全統合された分散型・オフライン対応のバグトラッカーです。バグデータは標準的なGitリポジトリ内に保存されるためベンダーロックインを防ぎ、プロジェクトのファイルには変更を加えません。一覧表示やオープンなどの操作は数ミリ秒で完了する高速性が特徴です。

CLI（git bug add、git bug lsなど）に加え、対話的なターミナルUI、GraphQL APIを備えたWeb UIの3種類のインターフェースを提供し、GitHub・GitLab・Jira・Launchpadとのブリッジ機能による相互同期も可能です。Go言語で実装され、GPLv3ライセンスで公開されています。

出典が伝えている要点

  • git-bugはGitリポジトリに完全に統合されたバグ追跡ツールである
  • git-bugは分散型でオフラインでも動作する
  • git-bugはバグデータを標準的なGitリポジトリ内に保存し、ベンダーロックインを防ぐ
  • git-bugはバグの一覧表示やオープンなどの操作が数ミリ秒で完了する高速性を持つ
  • git-bugはプロジェクトのファイルに変更を加えない（プロジェクトを汚染しない）
  • git-bugはCLI（git bug add、git bug lsなど）を提供する
  • git-bugは対話的なターミナルUI（git bug termuiコマンド）を提供する
  • git-bugはGraphQL APIと統合されたWeb UI（git bug webuiコマンド）を提供する
  • git-bugはGitHub、GitLab、Jira、Launchpadとのブリッジ機能により相互同期が可能である
  • git-bugはGo言語で実装されている
  • git-bugはGPLv3ライセンスで公開されている
  • git-bugはGit内でDAG（有向非巡回グラフ）としてエンティティを表現する仕様になっている
