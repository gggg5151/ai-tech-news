Anthropic公式のGitHub Action、claude-code-action

公式github.com2026.09.27

claude-code-actionは、AnthropicがGitHub上のPull RequestとIssueに対応する汎用GitHub Actionとして開発・メンテナンスしているツールです。Claude AIがコード変更の実装、コードレビュー、質問への回答を自動で行い、ワークフローのコンテキストに基づいて実行モードを自動選択する機能を持ちます。

GitHub APIとファイル操作にアクセスでき、GitHubランナー上で完全に実行されます。導入はClaude Codeターミナルで/install-github-appコマンドを実行するだけですが、リポジトリ管理者権限とGitHub Appのインストール権限が必要です。認証方法はAnthropic API、Amazon Bedrock、Google Vertex AI、Microsoft Foundryのいずれかから選べます。

MITライセンスで公開されており、現在の最新はv1.0です。v0.xからのマイグレーションガイドも用意されています。

出典が伝えている要点

  • claude-code-actionはGitHubのPull RequestとIssueに対応する汎用GitHub Actionである
  • Claude AIがコード変更の実装、コードレビュー、質問への回答を自動で行う
  • ワークフローコンテキストに基づいて実行モードを自動選択する機能を持つ
  • GitHub APIとファイル操作にアクセス可能である
  • GitHubランナー上で完全に実行される
  • 導入には /install-github-app コマンドをClaude Codeターミナルで実行する
  • セットアップにはリポジトリ管理者権限とGitHub Appのインストール権限が必要
  • 認証方法としてAnthropic API、Amazon Bedrock、Google Vertex AI、Microsoft Foundryのいずれかが利用できる
