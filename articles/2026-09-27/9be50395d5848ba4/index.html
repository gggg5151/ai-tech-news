あらゆるアプリをCLI化しエージェントに操作させる

公式github.com2026.09.27

CLI-Anything(HKUDS)は、ソースコードやリポジトリから自動的にCLI(コマンドラインインターフェース)を生成し、AIエージェントがGUI操作ではなく構造化されたコマンドを通じてデスクトップアプリケーションを制御できるようにするオープンソースプロジェクトです。「Tomorrow's Users will be Agents」というビジョンを掲げています。

コード分析から実装、テスト、ドキュメント生成、PyPI発行までを自動化する7段階のパイプラインを持ち、Claude Code、Cursor、Pi Coding Agent、OpenClaw、Codexなど複数のAIコーディングプラットフォームに対応しています。Blender、GIMP、LibreOffice、Inkscape、ComfyUI、Ollama、Zoom、OBS Studioなど18以上のメジャーアプリケーションをサポートし、1,732件のユニットテストと579件のエンドツーエンドテストの合計2,461件以上のテストで検証済みだとしています。

pip install cli-anything-hubでCLI-Hubをインストールでき、Claude Codeプラグイン導入後は/cli-anythingコマンドで新しいCLIを生成できます。Apache 2.0ライセンスで公開されています。

出典が伝えている要点

  • CLI-AnythingはHKUDSによるオープンソースプロジェクトである
  • ソースコードやリポジトリから自動的にコマンドラインインターフェース(CLI)を生成する機能を持つ
  • AIエージェントがGUI操作ではなく構造化されたコマンドインターフェースを通じてデスクトップアプリケーションを制御できるようにすることを目的としている
  • 「Tomorrow's Users will be Agents」というビジョンを掲げている
  • コード分析から実装、テスト、ドキュメント生成、PyPI発行までを自動化する7段階のパイプラインを持つ
  • Claude Code、Cursor、Pi Coding Agent、OpenClaw、Codexなど複数のAIコーディングプラットフォームに対応している
  • Blender、GIMP、LibreOfficeなど実在のアプリケーションと統合している
  • 1,732件のユニットテストと579件のエンドツーエンドテストの合計2,461件以上のテストが実施されている
  • サポート対象ソフトウェアで18以上のメジャーアプリケーションが含まれる(GIMP、Blender、Inkscape、LibreOffice、ComfyUI、Ollama、Zoom、OBS Studioなど)
  • pip install cli-anything-hubでCLI-Hubをインストールできる
  • Claude Codeプラグインをインストール後、/cli-anything コマンドで新しいCLIを生成できる
  • プロジェクトはApache 2.0ライセンスの下で公開されている
