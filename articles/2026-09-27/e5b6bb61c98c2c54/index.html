ローカルLLMのWeb検索手段まとめ

報道note.com2026.09.27

ローカルLLMで利用できるWeb検索サービス・APIをまとめた記事です。Brave Search APIは独自の300億ページ超のWebインデックスを持ち、月$5分の無料クレジットとMCP Serverを提供します。Ollama Web Searchはweb_searchとweb_fetchの2機能を持ち、Python/JavaScriptライブラリに統合できます。

Exaは1,000リクエストあたり$7で月$10分の無料クレジットとMCP対応、TavilyはSearch/Extract/Crawl/Researchの機能を持ち月1,000APIクレジットまで無料、Parallel Searchは1回$0.001〜$0.005で月$5分の無料クレジット、Perplexity Search APIはドメイン・期間・地域の指定が可能です。SearXNGとDuckDuckGoは無料で利用できます。

これらはOllama、LM Studio、OpenClaw、OpenCodeで利用可能とされており、用途に応じた選択の参考情報として整理されています。

出典が伝えている要点

  • Brave Search APIは独自の300億ページ超のWebインデックスを持ち、月$5分の無料クレジットとMCP Serverを提供する
  • Ollama Web Searchはweb_searchとweb_fetchの2機能を持ち、Python/JavaScriptライブラリに統合できる
  • Exaは1,000リクエストあたり$7で、月$10分の無料クレジットと初回$10ボーナスを提供し、MCPに対応している
  • TavilyはSearch/Extract/Crawl/Researchの機能を持ち、月、1,000APIクレジットまで無料で利用できる
  • Parallel Searchは1回あたり$0.001～$0.005で、月$5分の無料クレジットを提供する
  • Perplexity Search APIはドメイン・期間・地域の指定が可能である
  • SearXNGとDuckDuckGoは無料で利用できる
  • これらのWeb検索サービスはOllama、LM Studio、OpenClaw、OpenCodeで利用可能である
