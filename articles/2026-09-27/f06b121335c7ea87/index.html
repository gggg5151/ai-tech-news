エージェント専用の実行基盤、Agent Substrate

公式github.com2026.09.27

Agent Substrate(agent-substrate/substrate)は、自律AIエージェントの実行に特化したセキュアなランタイムです。Kubernetes上に構築され、microVMやgVisorなど複数のサンドボックス技術を使い分けることで、標準的なコンテナランタイムと比べて10倍高い密度で数百万のサンドボックスを実行できるとしています。

500ミリ秒未満での再開操作や秒間500以上の中断/再開アクティベーションを実現し、ゼロトラスト型のカーネル・ネットワーク分離によるセキュリティを備えています。Agent Development Kit、LangChain、Claude Code、MCPなど複数のエージェントフレームワークに対応するフレームワーク非依存の設計です。

現在はpre-1.0段階でAPIの後方互換性は未保証ですが、Counter Demo、Sandbox Demo、Claude Code Multiplexなど6つのデモが提供されており、Google GroupやCNCF Slackでコミュニティ活動も行われています。

出典が伝えている要点

  • Agent Substrateは自律エージェント時代向けに構築された、セキュアなエージェント実行ランタイムである
  • 標準的なコンテナランタイムと比べて10倍高い密度で数百万のサンドボックスを実行できるとされる
  • 500ミリ秒未満の再開操作を実現するとされる
  • 秒間500以上の中断/再開アクティベーションを実現するとされる
  • ゼロトラスト型のカーネルとネットワーク分離によるセキュリティを備える
  • 複数のサンドボックス技術(microVM、gVisor)をサポートする
  • Kubernetesの上に構築されている
  • Agent Development Kit、LangChain、Claude Code、Model Context Protocol(MCP)など複数の構成に対応するフレームワーク非依存設計である
  • Counter Demo、Sandbox Demo、Claude Code Multiplexなど6つのデモプロジェクトが提供されている
  • プロジェクトは現在pre-1.0段階であり、後方互換性は保証されていない
  • 最新のKubernetesリリースと1つ前のマイナーバージョンのサポートを目指している
  • Google Groupの「ate-dev」やCNCF Slackで週次ミーティングが開催されている
