DeepSeekのエージェント訓練基盤、1日300万サンドボックスを処理

体験談arxiv.org2026.09.28

DeepSeekが自社のエージェント訓練用サンドボックス基盤「DeepSeek Elastic Compute (DSec)」を発表した論文です。大規模言語モデルのエージェント訓練を支える本番運用級の実行環境で、FnCall・コンテナ・microVM・フルVMという4種類のサンドボックスバックエンドを単一の統一SDKで扱えるように設計されています。

1つの本番ユニットで約160ノードを使い、1日あたり約300万個のサンドボックスを処理できるスケーラビリティを持ち、38万以上の同時実行サンドボックスと秒間5000以上の作成レートを維持できると主張されています。独自の分散ファイルシステム「Fire-Flyer File System (3FS)」を用い、強化学習フレームワークと連携する設計になっています。著者は130名以上、筆頭著者はJialiang Huang氏です。

出典が伝えている要点

  • 論文タイトルは『DeepSeek Elastic Compute (DSec): A Sandbox Infrastructure for Effective Agentic Training at Scale』である
  • 著者は130名以上で、筆頭著者はJialiang Huangである
  • DSecはFnCall、コンテナ、microVM、フルVMという4種類のサンドボックスバックエンドを統一されたSDKで提供する
  • DSecは1つの本番ユニットで約160ノードを使用する
  • DSecは1日あたり約300万個のサンドボックスを処理できる
  • DSecは38万以上の同時実行サンドボックスをサポートする
  • DSecは秒間5000以上のサンドボックス作成レートを維持できる
  • DSecはFire-Flyer File System (3FS)という分散ファイルシステムを使用する
  • DSecは強化学習フレームワークとの連携を想定した設計になっている
  • 論文の投稿日は2026年9月19日である
  • 論文のカテゴリは分散・並列・クラスタコンピューティングである
