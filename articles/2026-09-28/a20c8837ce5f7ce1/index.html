箇条書きからAWS構成図を自動生成するClaude Code Skill

体験談github.com2026.09.28

Claude Code向けのSkill「aws-drawio-diagram-skill」を紹介するリポジトリです。ユーザーが箇条書きでAWS構成を説明するだけで、AWS公式アイコンを使った整理されたdraw.io形式の構成図を自動生成できます。「AWS Cloud→リージョン→VPC→AZ」というネスト構造を自動配置し、上から下へのリクエストフローを表示、サブネットをグラデーションで塗り分けてパブリック/プライベートを判別する機能も備えています。

実行にはPython 3とClaude Codeが必要で、Claude Opus 5.5の使用が推奨されており、1図あたり3〜4分・約1ドル相当のコストがかかるとのことです。Sonnet 5でも利用できますが処理時間は延びるとされています。ライセンスはApache License 2.0です。

出典が伝えている要点

  • このツールはClaude Codeで利用可能なSkillである
  • AWS構成図をdraw.io形式で自動生成する
  • ユーザーが箇条書きでAWS構成を説明するだけで構成図を作成できる
  • AWS公式アイコンを採用している
  • AWS Cloud→リージョン→VPC→AZというネストされた枠を自動配置する機能がある
  • 上から下へのリクエストフロー表示を行う
  • サブネットをグラデーションで塗り分けてパブリック/プライベートを判別する
  • 「AWS構成図を描いて」と依頼すると自動認識される

  • Claude Opus 5.5の使用が推奨されており、1図あたり3-4分、約1ドル相当のコストがかかる
