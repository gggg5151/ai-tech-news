Docker、AIエージェント向けクラウド型サンドボックスを発表 ローカルと中断なく行き来

報道publickey1.jp2026.09.28

Docker社は、AIエージェント向けのクラウドベースのサンドボックス環境「Docker Cloud Sandboxes」を発表しました。最大の特徴は、ローカルマシン上の「Docker Sandboxes」とクラウド上の「Docker Cloud Sandboxes」の間で、稼働中のサンドボックスを中断せずに移動できる点で、両者は同じMicroVM技術・CLIインターフェイス・トラストモデルを共有しています。

大規模なコーディング作業のためにローカルPCを常時稼働させる必要をなくすことや、100以上ものサブエージェントを起動する際のローカルのリソース制約を解消することを狙いとしています。サンドボックスは数百ミリ秒での高速起動に対応します。

料金は従量課金制で、最小構成「Micro」(1vCPU・2GB)は1時間0.07ドル(約10円)、最大構成「XL」(16vCPU・32GB)は1時間1.12ドル(約168円)です。新規申し込み者には250ドルの無料クレジットが提供されます。

出典が伝えている要点

  • Docker社が「Docker Cloud Sandboxes」を発表した

  • ローカルマシン上の「Docker Sandboxes」とクラウド上の「Docker Cloud Sandboxes」間で、稼働中のサンドボックスを中断なく移動できる
  • ローカルとクラウドの両サンドボックスは同じMicroVM技術・CLIインターフェイス・トラストモデルを採用している
