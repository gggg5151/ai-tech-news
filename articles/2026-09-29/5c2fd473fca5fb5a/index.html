Opus 5.5を使いこなすプロンプト設計指針

報道platform.claude.com2026.09.29

Anthropicが公式ドキュメント「Prompting Claude Opus 5.5」を公開しました。前モデルClaude Opus 5との挙動差異と、それに対応したプロンプト設計のコツをまとめた実践的なガイドです。

Opus 5.5は出力トークンの生成速度が前モデルより30%以上速く、同じタスクをより少ないトークンで完了する傾向があるとされています。一方でデフォルトのeffort（思考量の設定）は"medium"に変更され（Opus 5は"high"）、Anthropicのテストではmedium設定でもコーディングやナレッジワークの評価でOpus 5のhigh設定と同等以上の性能を示したとしています。複数のコーディング評価ではlow effortでもhigh effortに近い性能をより低コストで達成できるとのことです。

注意点として、Opus 5.5はOpus 5と異なりhigh effort以下でのthinking無効化を受け付けません。また、effortの値をリクエスト間で変更するとプロンプトキャッシュが無効化される点や、長いエージェント実行のためmax_tokensを128,000（モデルの最大値）に設定するとうまく機能した、といった実践的な知見も紹介されています。安全性分類器についても、バイオロジー・サイバーセキュリティ・推論抽出の3カテゴリで動作することが明記されています。

出典が伝えている要点

  • Claude Opus 5.5はClaude Opus 5より出力トークン生成速度が30%以上速い
  • Claude Opus 5.5は同じタスクをClaude Opus 5より少ないトークンで完了する傾向がある
  • Claude Opus 5.5のデフォルトeffortは"medium"であり、Claude Opus 5のデフォルトは"high"である
  • Anthropicのテストでは、Claude Opus 5.5はデフォルトのmedium effortで、コーディングおよびナレッジワークの評価においてClaude Opus 5のhigh effortと同等以上の性能を示した
  • 複数のコーディング評価において、Claude Opus 5.5のlow effortはhigh effortに近い性能をより低いコストで達成する
  • Claude Opus 5.5はClaude Opus 5と異なり、high effort以下でのthinking無効化(thinking: {type: disabled})を受け付けない
  • 長いagenticターンのためにmax_tokensを128,000(モデルの最大値)に設定することがAnthropicのテストでうまく機能した
  • effortの値をリクエスト間で変更すると、プロンプトキャッシュが無効化される
  • Claude Opus 5.5はバイオロジー、サイバーセキュリティ、reasoning extraction(推論抽出)に関する安全性分類器を実行する
  • バイオロジーのセーフガードはClaude Fable 5.1と同じものであり、Claude Opus 5から見ると新規のものである
  • reasoning_extractionカテゴリでの拒否は、サーバー側フォールバックでは自動リトライされず、そのままユーザーに返される
  • Claude Opus 5.5はコンピュータ操作(画面キャプチャからの操作)において、デフォルトeffortで、Claude Opus 5がより高いeffort設定でのみ到達した成功率に達した

原文より

Claude Opus 5.5 generates output tokens more than 30 percent faster than Claude Opus 5 and tends to finish the same task with fewer tokens.
Effort level names don't correspond to the same amount of thinking across models: in Anthropic's testing, Claude Opus 5.5 at medium matches or exceeds Claude Opus 5 at high on coding and knowledge-work evaluations
