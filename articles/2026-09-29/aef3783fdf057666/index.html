AIゲートウェイ「Bifrost」、23以上のプロバイダーを単一APIで統合

公式github.com2026.09.29

Maxim AIが開発するオープンソースのAIゲートウェイ「Bifrost」です。「The fastest way to build AI applications that never go down」を掲げ、OpenAI・Anthropic・AWS Bedrockなど23以上のプロバイダー・1,000以上のモデルへ、OpenAI互換の単一APIで接続できます。

自動フェイルオーバーやロードバランシングに加え、Model Context Protocol（MCP、外部ツールをAIに統合するための規格）によるツール統合、セマンティックキャッシング、テキスト・画像・音声のマルチモーダル対応など機能は幅広いです。予算管理やOIDC/OAuth 2.0によるユーザープロビジョニング、Prometheus監視といったエンタープライズ向け機能も備えます。Go言語で実装されDocker・Kubernetes・Helmに対応、Apache 2.0ライセンスで公開されており、現在8.4kスターを集めています。

出典が伝えている要点

  • Bifrostは「The fastest way to build AI applications that never go down」というコンセプトを掲げるAIゲートウェイである
  • BifrostはOpenAI、Anthropic、AWS Bedrockなど23以上のプロバイダーへの統一インターフェースを単一OpenAI互換APIで提供する
  • Bifrostは自動フェイルオーバーとロードバランシング機能を持ち1000以上のモデルをサポートする
  • BifrostはModel Context Protocol(MCP)による外部ツール統合機能とセマンティックキャッシング機能を持つ
  • Bifrostはテキスト・画像・音声・ストリーミングのマルチモーダルに対応し、カスタムプラグインシステムを持つ
  • Bifrostは予算管理と使用量追跡機能、OIDC/OAuth 2.0によるユーザープロビジョニングに対応する
  • BifrostはPrometheus統合による監視機能を持つ
  • BifrostはGo言語で実装され、Docker・Kubernetes・Helmに対応する
  • BifrostはApache 2.0ライセンスで公開されている
  • BifrostはMaxim AIによって開発・保守されている
  • リポジトリは8.4kスター、1.3kフォークを記録している
  • リポジトリは509イシュー、631プルリクエストを記録している
