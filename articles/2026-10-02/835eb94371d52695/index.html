Claude Code v2.1.287、プラグイン拡張「Claude Mods」追加

公式github.com2026.10.02

Claude Codeのv2.1.287がリリースされました。新機能「Claude Mods」により、プラグインがより深い動作を修正できるようになりました。組み込みMod「You should know」も追加され、サイドエージェントがユーザーやClaude自身が見落とす可能性のある点をフラグします（有効化コマンドは/plugin enable cc-plugin-you-should-know@builtin）。エージェントビューには、セッション名・タスク名にマッチする「n:<text>」フィルタも追加されました。

不具合修正としては、危険なrmコマンドの安全装置が失われる問題や、PNG/JPEG/WebPが8000ピクセルを超える場合に画像送信が失敗する問題（スケールダウンしたコピーを送信するよう変更）が解消されています。

出典が伝えている要点

  • リリースのバージョンはv2.1.287である。
  • リリース者は@ashwin-antである。
  • コミットIDはh816ec21(816ec21)である。
  • 新機能として「Claude Mods」が追加され、プラグインがより深い動作を修正できるようになった。
  • 組み込みMod「You should know」が追加され、サイドエージェントがユーザーやClaudeが見落とす可能性のあることをフラグする。
  • 「You should know」の有効化コマンドは「/plugin enable cc-plugin-you-should-know@builtin」である。
  • エージェントビューに「n:<text>」フィルタが追加され、セッション名とタスク名にマッチする。
  • OpenTelemetryのuser_promptイベントにprompt_textが追加された。
  • MCPサーバーが2025-11-25プロトコルのURLプロンプト(サインイン等)に対応した。
  • 危険なrmコマンドの安全装置が失われる問題が修正された。
  • PNG/JPEG/WebPが8000ピクセルを超える場合に送信が失敗する問題が修正され、スケールダウンしたコピーを送信するようになった。
  • セルフホストランナーに、GitHub CLIなしのmacOS/Linux向けの組み込みgh api(REST only)が追加された。
