無料OSSコーディングツール「Pi 1.0」が正式リリース

報道gigazine.net2026.10.03

無料かつオープンソースのAIコーディングツール「Pi 1.0」が、開発元Earendilにより2026年10月1日に正式リリースされました。コア機能はファイル読み取り(read)、コマンド実行(bash)、ファイル修正(edit)、ファイル作成(write)というシンプルな設計です。

新機能として、MCP（Model Context Protocol、AIモデルと外部ツールをつなぐ標準規格）への標準対応による外部ツール連携、15以上のプロバイダーに対応したAIモデル切り替え機能、ツール操作をJavaScriptコードとしてまとめて実行する「Codemode」、必要なツールだけ後から読み込む「Deferred tool loading」が追加されました。公式サイト(pi.dev)から無料で入手できます。

出典が伝えている要点

  • ツール名は「Pi 1.0」である
  • 開発元はEarendilである
  • Pi 1.0は2026年10月1日に正式リリースされた
  • Pi 1.0はオープンソースである
  • Pi 1.0は無料で利用できる
  • Pi 1.0はhttps://pi.dev/から入手できる
  • Pi 1.0のコア機能はファイル読み取り(read)、コマンド実行(bash)、ファイル修正(edit)、ファイル作成(write)である
  • Pi 1.0はMCP(Model Context Protocol)に標準対応し外部ツール連携が可能になった
  • Pi 1.0にはツール操作をJavaScriptコードとしてまとめて実行する「Codemode」が追加された
  • Pi 1.0には必要なツールだけを後から読み込む「Deferred tool loading」が追加された
  • Pi 1.0は15以上のプロバイダーに対応したAIモデル切り替え機能を持つ
  • Pi 1.0には複数のAIモデルを組み合わせて運用できる仮想モデル拡張機能がある
