WhatsAppをClaudeから操作するMCPブリッジ

公式github.com2026.10.06

ClaudeやCursorなどMCP対応AIが個人のWhatsAppアカウントと連携し、メッセージの検索・閲覧・送信を行えるようにするOSSブリッジです。Go製のWhatsAppブリッジ（WhatsApp Web APIに接続しQRコード認証、メッセージはローカルのSQLiteに保存）と、Python製のMCPサーバーの二層構成になっています。

機能としては連絡先検索、メッセージ検索、チャット一覧表示、個人・グループ向けメッセージ送信、画像・動画・文書・音声メッセージの送受信などが挙げられています。必須環境はGo、Python 3.6+、UV、Claude Desktop（またはCursor）で、FFmpegはオプションです。

READMEでは「すべてのメッセージはローカルのSQLiteデータベースに保存され、エージェントがツールを通じてアクセスした時だけLLMに送信される」とプライバシー重視の設計が強調されていますが、同時にプロンプトインジェクションにより個人情報が流出するリスクがある旨の警告も記載されています。MITライセンスです。

出典が伝えている要点

  • このプロジェクトはClaude(やCursor等)が個人のWhatsAppアカウントにアクセスして操作するためのMCPブリッジである
  • アーキテクチャはGo製のWhatsAppブリッジとPython製のMCPサーバーの二層構成である
  • Goブリッジは WhatsApp Web API に接続し、QRコード認証を処理する
  • メッセージはローカルのSQLiteデータベースに保存される
  • READMEには「すべてのメッセージはローカルのSQLiteデータベースに保存され、エージェントがツールを通じてアクセスした時だけLLMに送信される」と記載されている
  • 必須環境としてGo、Python 3.6+、UV、Claude Desktop(またはCursor)が挙げられており、FFmpegはオプションで推奨されている
  • 機能として連絡先検索、メッセージ検索、チャット一覧表示、メッセージ送信(個人・グループ対応)、画像・動画・文書・音声メッセージの送受信、メディアダウンロードが挙げられている
  • ライセンスはMITである
  • READMEには、プロンプトインジェクションにより個人情報が流出するリスクがある旨の警告が記載されている
