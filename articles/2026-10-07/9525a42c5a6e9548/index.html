ベクトルDB不要の階層インデックス型RAG「PageIndex」

公式github.com2026.10.07

VectifyAIが公開したPageIndexは、ベクトルデータベースやチャンキングを使わず、文書から階層的なツリーインデックスを構築してLLMの推論能力で検索する「Vectorless, Reasoning-based RAG」を標榜するOSSです。人間が目次や見出しを辿って報告書を読む方法を模倣した検索方式で、金融報告書のような複雑な長文文書向けに最適化されています。

pip install -U pageindexでインストールでき、インデックス生成コストは1ページあたり約0.001ドルです。FinanceBenchベンチマークでは98.7%の精度を達成し、同条件のベクトルRAGの50%を大きく上回ったとしています。

9〜1,098ページの文書のインデックス作成は13秒〜4.5分で完了し、420ページの文書ではネイティブPDF入力と比べて16.6倍のコスト削減になるとしています。Local版・Cloud版が用意され、MITライセンスで公開されています。

出典が伝えている要点

  • PageIndexはVectifyAIが開発したリポジトリである
  • PageIndexはベクトルデータベースを使わない「Vectorless, Reasoning-based RAG」を採用している
  • PageIndexは文書のチャンキングを行わない
  • PageIndexは階層的なツリーインデックス構造を構築して文書を検索する
  • pip install -U pageindexでインストールできる
  • インデックス生成のコストは1ページあたり約0.001ドルとされている
  • FinanceBenchというベンチマークでPageIndexは98.7%の精度を達成したとされている
  • 同じFinanceBenchでベクトルRAGは50%の精度だったとされている
  • 9〜1,098ページの文書のインデックス作成に13秒〜4.5分かかるとされている
  • 420ページの文書でネイティブPDF入力と比べて16.6倍のコスト削減があるとされている
  • PageIndexにはLocal版とCloud版がある
  • リポジトリはMITライセンスで公開されている
