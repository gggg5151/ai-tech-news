コーディングエージェントの信頼性、スケールでは自然に育たない

公式arxiv.org2026.10.07

「Teaching Agents to Code Reliably」は、自律型コーディングエージェント（リポジトリ内の課題解決を行うAIエージェント）の信頼性を高める手法を提案する論文です。著者らは、エージェントの「位置の多様性」「編集方法の多様性」「検証の信頼性」という3つの振る舞いは、モデルを大規模化するだけでは自然に得られず、明示的に教えることができると主張しています。

教師ありファインチューニングと強化学習を組み合わせた手法により、SWE-bench Verifiedで52.8%の解決率を達成し、ベースライン比48.1%のエージェントステップ数で同等の性能を実現したとしています。pass@1は31.9%から43.0%、pass@8は46.7%から60.7%に向上し、7Bから30Bのモデルサイズで一貫した改善が見られたとしています。

出典が伝えている要点

  • 論文タイトルは「Teaching Agents to Code Reliably」である
  • 著者はMuhammad Ahmed Mohsin、Myeongsoo Kim、Kangrui Ruan、Shweta Garg、Varun Kumar、Murali Krishna Ramanathanである
  • 論文は自律型コーディングエージェントの『位置の多様性』『編集方法の多様性』『検証の信頼性』という3つの重要な振る舞いに着目している
  • 論文は、この3つの振る舞いはモデルのスケール拡大の副産物ではなく、教えることが可能だと主張している
  • 位置の多様性の向上により、エージェントが同じ場所に繰り返しアクセスすることを回避できるとしている
  • 編集の多様性の活用により、相補的な問題解決が可能になるとしている
  • 検証プロセスの改善により、不正確な修正を受け入れてしまう割合を削減したとしている
  • SWE-bench Verifiedにおいて52.8%の解決率を達成したと報告している
  • ベースライン比で48.1%のエージェントステップ数で同等の性能を実現したと報告している
  • 教師ありファインチューニングと強化学習を組み合わせることで、pass@1を31.9%から43.0%に向上させたと報告している
  • 同手法によりpass@8を46.7%から60.7%に向上させたと報告している
  • 7Bから30Bのモデルサイズにおいて一貫した改善が見られたと報告している
