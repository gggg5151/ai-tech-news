Agent Lightning v1.0、3500行の軽量エージェントRLフレームワーク

公式microsoft.com2026.10.09

Microsoft Researchは2026年10月7日、強化学習（RL）でAIエージェントを訓練するための軽量フレームワーク「Agent Lightning v1.0」を発表しました。コード規模は約3,500行で、「Harnessed Agentic RL」という新しい学習パラダイムを導入しています。

最大の特徴は、既存のエージェントの実行環境（harness）をそのまま強化学習に参加させられる点です。学習用に別途エージェントを作り直す必要がなく、エージェントとLLMの間にLLMプロキシを挿入するだけで、学習時と本番運用時の挙動を一致させられます。「本番で使うハーネスが、そのまま学習中の強化学習に直接参加する」と説明されています。

Qwen3.5-9Bを用いた検証では、AIエージェントのコード修正能力を測るベンチマークSWE-bench VerifiedのPass@1（1回の試行で正解できた割合）が41.8%から56.4%まで改善しました。学習データは約6,000サンプル、Collocated Async RLという手法により同期型のRLより約2倍の速度向上も達成しています。商用サンドボックスに依存せず、標準的なKubernetesジョブとして動作する点も実用上の利点です。

出典が伝えている要点

  • Microsoft Researchがフレームワーク「Agent Lightning v1.0」を発表した
  • Agent Lightning v1.0は「Harnessed Agentic RL」という学習パラダイムを導入している
  • フレームワークのコード規模は約3,500行である
  • 記事の公開日は2026年10月7日である
  • 記事の著者はZhiyuan He(Research SDE II)とYuqing Yang(Principal Research SDE Manager)である
  • 検証にはQwen3.5-9Bモデルが使用された
  • この手法によりSWE-bench VerifiedでのPass@1が41.8%から56.4%に改善した(14.6ポイント向上)
  • 学習データセットの規模は約6,000サンプルである
  • Collocated Async RLは同期RLに比べて約2倍の速度向上を達成した
  • 本フレームワークは商用サンドボックスに依存せず標準的なKubernetesジョブとして動作する
  • 主要コンポーネントはAPI Gateway、Rollout Controller、Customized Trainerである
  • この手法ではエージェントのharnessとLLMの間にLLMプロキシを挿入する方式を採用している
