Docker公式、YAMLでAIエージェントを作る「Docker Agent」公開

報道github.com2026.10.09

Docker社がGitHubで「Docker Agent」を公開しています。YAMLの宣言的設定によりコードを書かずにAIエージェントを構築・実行・共有できるツールで、OpenAI、Anthropic、Geminiなど複数のAIプロバイダーに対応しています。

複数のエージェントが協調動作するマルチエージェントアーキテクチャや、MCP（AIとツールを連携させる標準プロトコル）を含むツールエコシステムへの対応、思考・タスク・メモリツールを用いた推論、RAG（検索拡張生成）機能などを備えます。YAMLファイルでエージェントを定義し、docker agent runコマンドで実行する仕組みです。

Docker Desktop 4.63以上であればdocker agentコマンドをそのまま利用できるほか、Homebrewでのbrew install docker-agent、GitHub Releasesからのバイナリ取得にも対応しています。ライセンスはApache-2.0です。

出典が伝えている要点

  • リポジトリ名はDocker Agentで、Docker Engineeringが開発した
  • YAMLの宣言的設定によりコードを書かずにAIエージェントを作成できるとされている
  • 複数エージェントが協調動作する「マルチエージェント アーキテクチャ」を備える
  • MCPサーバーを含むツールエコシステムに対応する
  • OpenAI、Anthropic、Geminiなど複数のAIプロバイダーに対応する
  • 思考・タスク・メモリツールを用いた高度な推論機能を持つ
  • RAG(検索拡張生成)機能を備える
  • YAMLファイルでエージェントを定義し、docker agent runコマンドで実行する
  • Docker Desktop 4.63以上であればdocker agentコマンドで利用可能
  • Homebrewでbrew install docker-agentとしてインストールできる
  • GitHub Releasesからバイナリを取得することもできる
  • Apache-2.0ライセンスで公開され、Docker Inc.が作成・管理する公式リポジトリである
