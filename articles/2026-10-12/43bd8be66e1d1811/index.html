Data Agent Kit、GAでMCP経由15以上のサービスに接続

報道zenn.dev2026.10.12

Google Cloudの「Data Agent Kit」について、著者Sho氏が公式資料を整理した調査記事です。Data Agent KitはMCP（Model Context Protocol、AIエージェントが外部ツールやデータに接続するための標準規格）を使い、BigQueryやSpannerなど15以上のGoogleデータクラウドサービスにエージェントが接続できるようにする製品で、2026年10月1日にGA（一般提供）が発表されました。

用途別の「スキル」（プリセット手順）も用意されており、グラフ設計を支援する「bigquery-graph-author」や、AWS GlueとDatabricks Unity Catalogと連携する「federate-lakehouse-catalog」などが紹介されています。利用にはNode.jsとGoogle Cloud CLI、roles/mcp.toolUserというIAMロールが必要で、著者自身は「本記事は調査記事です。実測は行っていません」と明記しています。

出典が伝えている要点

  • Google Cloud Data Agent Kitは15以上のGoogleデータクラウドサービスに接続できる
  • 対応サービスにはBigQuery、Bigtable、Spanner、AlloyDB、Cloud SQL、Cloud Storage、Knowledge Catalog、Managed Service for Apache Spark、Dataflow、Cloud Airflowが含まれる
  • Data Agent KitはMCP(Model Context Protocol)を採用している
  • スキル「bigquery-graph-author」はグラフ設計・検証用である
  • スキル「bigtable-basics」はBigtable向けアクセスパターン設計を支援する
  • スキル「federate-lakehouse-catalog」はAWS GlueおよびDatabricks Unity Catalogとの連携用である
  • スキル「gcp-pipeline-orchestration」はパイプライン定義の作成用である
  • Data Agent KitのGA(一般提供)発表は2026年10月1日である
  • Data Agent Kitの利用にはNode.jsとGoogle Cloud CLIが必須である
  • 利用には roles/mcp.toolUser というIAMロールが要求される
  • 自動デプロイはGitHub Actionsのみ対応している
  • 著者は記事冒頭で本記事は調査記事であり実測は行っていないと明記している
