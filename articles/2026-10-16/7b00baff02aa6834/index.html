Metaの新オープンウェイトモデル「Muse Spark Open」公開

体験談research.meta.ai2026.10.16

Metaの研究ブログが2026年10月15日付で伝えた記事によると、米国産のオープンウェイト言語モデル（重みが公開され誰でも利用できるモデル）「Muse Spark Open」が公開されました。エージェント的な作業やコーディング用途に特化したモデルで、総パラメータ数816B、実際の計算に使われるアクティブパラメータは42Bという規模だと紹介されています。コンテキストウィンドウ（一度に処理できる入力の長さ）は1Mトークンに達するとのことです。

特徴的なのは動作環境の広さです。記事では、Apple M5 Ultra搭載のMac Studioでも実行可能だとされ、AMD/NVIDIA製GPU向けにはカーネルレベルで1.03〜3.95倍の高速化が図られているといいます。API提供パートナーにはBaseten、Fireworks AI、Groq、Modal、Nebius、OpenRouter、Together AIが並び、Amazon SageMaker AI、Google Cloud Model Garden、Hugging Face、Microsoft Foundry Modelsといった主要プラットフォームからも入手できるとのことです。

対応する推論エンジンもSGLang、vLLM、TensorRT-LLM、Hugging Face Transformers、Apple MLX、llama.cpp、Unslothと幅広く、公開初日から広範なエコシステムでの利用を想定した設計だと記事は紹介しています。

出典が伝えている要点

  • Metaは2026年10月15日に「Muse Spark Open」をリリースした
  • Muse Spark Openは米国産のオープンウェイト言語モデルである
  • モデルはエージェント的作業とコーディングに特化している
  • 総パラメータ数は816Bである
  • アクティブパラメータ数は42Bである
  • コンテキストウィンドウは1Mトークンである
  • Apple M5 Ultra搭載Mac Studioで実行可能である
  • AMD/NVIDIA GPU向けにカーネルレベルで1.03〜3.95倍の高速化がある
  • API提供パートナーはBaseten、Fireworks AI、Groq、Modal、Nebius、OpenRouter、Together AIである
  • モデル配布先はAmazon SageMaker AI、Google Cloud Model Garden、Hugging Face、Microsoft Foundry Modelsである
  • 対応推論エンジン/フレームワークはSGLang、vLLM、TensorRT-LLM、Hugging Face Transformers、Apple MLX、llama.cpp、Unslothである
