Anthropic公式、Claude API活用のサンプル集「claude-quickstarts」

公式github.com2026.10.17

Anthropic公式のGitHubリポジトリ「claude-quickstarts」は、Claude APIを使ったアプリケーション構築をすぐに始められるデベロッパー向けサンプルプロジェクト集です。MITライセンスで公開され、スター18.0k、フォーク3.1kと人気が高く、顧客サポートAI、金融データ分析、PCやブラウザの自動操作（Computer Use/Browser Use）、自律型コーディングエージェント、Slack・Linear・Sentry・GitHubなど外部サービス連携のManaged Agentsまで、計17種類のサンプルを収録しています。

Computer Use DemoはClaudeによるデスクトップ操作を実現し、Browser Use DemoはPlaywrightと連携したブラウザ自動化でDOM操作・フォーム入力・コンテンツ抽出が可能です。Autonomous Coding AgentはClaude Agent SDKを搭載し、複数セッション間でGit経由の進捗保存を行います。各プロジェクトはディレクトリごとに分かれ、クローン後に依存関係をインストールしAPIキーを設定して実行する共通の流れになっています。

出典が伝えている要点

  • リポジトリ名はclaude-quickstartsで、Anthropic(anthropics)が所有している
  • ライセンスはMITである
  • スター数は18.0k、フォーク数は3.1k、ウォッチャー数は175である
  • リポジトリにはClaude API利用のサンプルプロジェクトが計17種類収録されている
  • Computer Use Demoはclaudeによるデスクトップ操作を実現し、computer_toolset_20260801に対応する
  • Browser Use DemoはPlaywrightと連携したブラウザ自動化デモで、DOM操作・フォーム入力・コンテンツ抽出機能を持つ
  • Browser Toolset QuickstartはChrome DevTools Protocol(CDP)を使った最小実装例でPythonとTypeScriptがある
  • Computer Toolset QuickstartはVNC(RFB)プロトコル経由の最小実装例でPythonとTypeScriptがある
  • Autonomous Coding AgentはClaude Agent SDKを搭載した自律型コーディングエージェントで、複数セッション間でGit経由の進捗保存を行う
  • Managed Agents: Chat SDKはVercel Chat SDKと統合したチャットアプリで、Web検索とライブツール実行表示機能を持つ
  • Managed Agents: MCP Server (TypeScript)はClaude DesktopとClaude.ai用のMCPサーバーである
  • Managed Agents: SentryはSentry統計情報トリアージエージェントでMCP OAuthに対応する
