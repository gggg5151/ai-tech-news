DeepSeekが検索・取得APIを提供開始

報道api-docs.deepseek.com2026.10.19

DeepSeekが、自社検索エンジンでウェブページを検索するSearch APIと、指定したURLの内容をMarkdown形式で取得するFetch APIという2つのツールを公開しました。Search APIは最大50件の結果を返却でき、site:やlang:、before:といった検索演算子にも対応しています。

料金はいずれも1,000リクエストあたり$0.75で、課金対象はHTTPステータス200を返した「成功したリクエスト」のみという設計です。失敗やタイムアウトは課金されません。レート制限は両APIとも5QPS（1秒あたりリクエスト数）で、認証にはAPIキーをAuthorizationヘッダーに含める必要があります。

出典が伝えている要点

  • DeepSeekはSearch APIとFetch APIという2つのツールを提供している。
  • Search APIのエンドポイントはPOST https://api.deepseek.com/v1/tools/searchである。
  • Fetch APIのエンドポイントはPOST https://api.deepseek.com/v1/tools/fetchである。
  • Search APIは自社の検索エンジンを使って関連ウェブページを検出する。
  • Fetch APIは個別のページ内容をMarkdown形式で取得する。
  • Search APIは最大50件の検索結果を返却できる。
  • Search APIはsite:、lang:、after:、before:などの検索演算子に対応している。
  • Search APIとFetch APIはいずれも1,000リクエストあたり$0.75の料金が課金される。
  • リクエストはHTTP 200を返した場合のみ課金対象となる。
  • Search APIとFetch APIのレート制限はどちらも５ QPS（1秒あたりリクエスト数）である。
  • Fetch APIにはアカウント単位エナドドメイン単位の追加のレート制限がある。
  • 両APIともAuthorizationヘッダーに「Bearer <DeepSeek APIキー>」を含めて認証する必要がある。
