Next.js devサーバーが無反応になったら.nextを消す

体験談zenn.dev2026.10.19

Next.jsの開発サーバーで、ボタンやフォーム操作への反応が消え、コンソール出力も出なくなる現象が報告されています。原因は.next/static/chunks/ディレクトリが空になり、Reactクライアントが起動できずSSR（Server Side Rendering、サーバー側でHTMLを生成する方式）のHTMLだけが表示された状態になることで、HMR（Hot Module Replacement、コード変更を即時反映する仕組み）のリビルドが中断されると発生しやすく、devサーバーの長時間連続稼働やブラウザ自動化ツールの使用時に起こりやすいといいます。

診断にはDevToolsのNetworkタブで_next/static/chunks/*.jsが404を返していないか確認する方法が有効です。解決策は「rm -rf .next && npm run dev」の実行で、筆者は1分以内に復旧できたと述べています。

出典が伝えている要点

  • 症状として、選択肢の変更やボタンクリックなどのフォーム操作イベントが発火しなくなる
  • 症状として、コンソール出力が表示されなくなる
  • 症状として、ページをリロードしても改善しない
  • 原因は.next/static/chunks/ディレクトリが空になることである
  • .next/static/chunks/が空になると、Reactクライアントが起動できずSSRのHTMLのみが表示される状態になる
  • この現象はHMR（Hot Module Replacement）のリビルドが中断されると発生しやすい
  • devサーバーを長時間連続稼働させている場合に発生しやすい
  • ブラウザ自動化ツールを使用している場合に発生しやすい
  • 診断方法として、ブラウザのDevToolsのNetworkタブで_next/static/chunks/*.jsが404エラーを返していないか確認することが推奨されている
  • 解決方法は「rm -rf .next && npm run dev」を実行することである
  • この方法で1分以内に復旧できるとされている
  • 著者「ミケ」は実際に自身が遭遇した問題を基にこの記事を書いている
