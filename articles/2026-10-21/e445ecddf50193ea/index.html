競合するAgent Skillsが引き起こす「takeover」現象

公式arxiv.org2026.10.21

論文「One Skill Takes Over: Clashing Agent Skills and a One-File Fix」は、複数のAIエージェント用「スキル」（振る舞いを指示するファイル）を同時に読み込ませると、一方のスキルが他方を支配してしまう「takeover」現象が起きることを実証しました。著者らは同じタスクに競合するルールを持つ16組のスキルペアからなるベンチマーク「SkillClash」を構築し、4B〜235Bパラメータの7モデル（GPT-4.1、Qwen3、Claude系を含む）で検証しています。

スキルを単独で与えた場合の規則遵守率は93〜99%でしたが、競合する2つのスキルを同時に与えると61〜62%まで低下しました。対策として、スキルファイルの末尾に両方のルールに従う例を1つ追加する「one-file fix」というシンプルな手法を提案し、大幅な改善を確認したとしています。

出典が伝えている要点

  • 論文タイトルは『One Skill Takes Over: Clashing Agent Skills and a One-File Fix』である
  • 著者はParsa Razmara、Seyedarmin Azizi、Ardalan Aryashadの3名である
  • 論文は2026年10月18日に提出された(arXiv番号2610.25064)
  • 研究では「SkillClash」という名称のベンチマークを構築した
  • SkillClashは同じタスクに対して競合するルールを持つ16組のスキルペアで構成される
  • 各スキルペアには検証可能な参照出力が用意されている
  • 評価には4Bから235Bパラメータまでの7つのモデルを用いた
  • 評価対象モデルにはGPT-4.1、Qwen3、Claude系モデルが含まれる
  • スキルが単独で与えられた場合の規則遵守率は93%から99%だった
  • 競合する2つのスキルが同時に与えられた場合の規則遵守率は61%から62%に低下した
  • 競合時には一方のスキルが他方を支配する「takeover」という現象が観察された
  • 解決策として、スキルファイルの末尾に両方のスキルに従う例を1つ追加する手法を提案した
