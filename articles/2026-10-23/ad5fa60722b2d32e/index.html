コードベースを知識グラフ化する「Graphify」

公式github.com2026.10.23

Graphifyは、コードベースとドキュメントやSQLスキーマ、設定ファイル、PDFなどをまとめて「クエリ可能なナレッジグラフ」に変換するツールです。Claude Code、Cursor、Codex、Gemini CLIなどAIコーディングアシスタント向けのスキルとして動作します。

tree-sitterによるAST（抽象構文木、プログラムの構造を木構造で表したもの）解析をローカル完結で行うため、LLM処理や外部依存は不要です。各接続は「EXTRACTED（ソースに明示）」か「INFERRED（解析で推定）」のどちらかにタグ付けされ、透明性を担保します。約40のプログラミング言語に加え、ドキュメントやPDF、画像、音声/動画ファイルにも対応し、埋め込みベースの検索ではなく実際のグラフ構造によるトラバーサル（経路をたどる探索）を実現します。/graphify .を実行するとgraph.html、GRAPH_REPORT.md、graph.jsonの3つの出力が生成されます。ライセンスはApache-2.0とMITのデュアルです。

出典が伝えている要点

  • Graphifyはコードベース、ドキュメント、SQLスキーマ、設定ファイル、PDFを「クエリ可能なナレッジグラフ」に変換するツールである
  • GraphifyはClaude Code、Cursor、Codex、Gemini CLIなどのAIコーディングアシスタント向けのスキルとして機能する
  • Graphifyはtree-sitterのASTを使ったローカル完結の解析を行う
  • Graphifyの解析はLLM処理や外部依存を必要としない
  • Graphifyは各接続を「EXTRACTED(ソースに明示的に記載)」または「INFERRED(解析により推定)」のいずれかにタグ付けする
  • Graphifyはファイル検索ではなく関係性の検索・トラバーサルを可能にするグラフベースのクエリを提供する
  • Graphifyは約40のプログラミング言語に対応する
  • Graphifyはドキュメント、PDF、画像、動画/音声ファイルにも対応する
  • Graphifyは埋め込みベースの検索(ベクトルストレージ)を使わず、実際のグラフ構造を作成する
  • Graphifyはuv tool install graphifyyまたはpipx install graphifyyでインストールできる
  • /graphify .コマンドを実行するとgraph.html、GRAPH_REPORT.md、graph.jsonの3つの出力が生成される
  • GraphifyはApache-2.0とMITのデュアルライセンスで提供されている
