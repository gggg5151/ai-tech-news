p10node/k10s の internal/update/semver.go を読む

GitHub で実物を見る ↗2026.10.09

k10sはKubernetesクラスタをマウスでも操作できるTUI（ターミナルUI）ツールで、Bubble Teaという非同期UIフレームワーク上に作られています。今回読むinternal/update/semver.goは、アプリの自動アップデート機能が「今のバージョンより新しいリリースが出ているか」を判定するために使うバージョン比較ロジックです。GitHubのリリースタグという実データを相手にする、教科書には出てこない泥臭い分岐（devビルドやビルドメタデータの扱い）が詰まっていて、Goの基本構文が実務でどう組み合わさるかを学ぶのにちょうど良い題材です。

コード

// Compare orders two versions: -1 if a sorts before b, +1 if after, 0 if
// they are the same release.
func Compare(a, b string) int {
	an, bn := Normalize(a), Normalize(b)
	if an == bn {
		return 0
	}

	aNum, aPre, aOK := split(an)
	bNum, bPre, bOK := split(bn)

	// An unparseable version ("dev", "main", a branch name) is older than
	// any real one; two of them fall back to a stable string order so the
	// comparison is still total.
	switch {
	case !aOK && !bOK:
		return strings.Compare(an, bn)
	case !aOK:
		return -1
	case !bOK:
		return 1
	}

	if c := compareNums(aNum, bNum); c != 0 {
		return c
	}
	return comparePre(aPre, bPre)
}

// …略…

// split separates "1.4.0-rc.1" into its numeric parts and its prerelease
// tail. ok is false when the numeric head isn't numeric at all.
func split(v string) (nums []int, pre string, ok bool) {
	head := v
	if i := strings.IndexByte(v, '-'); i >= 0 {
		head, pre = v[:i], v[i+1:]
	}
	if head == "" {
		return nil, "", false
	}
	for _, p := range strings.Split(head, ".") {
		n, err := strconv.Atoi(p)
		if err != nil || n < 0 {
			return nil, "", false
		}
		nums = append(nums, n)
	}
	return nums, pre, true
}

引用はリポジトリの実物と機械で照合しています。「// …略…」は省略した行です。

上から順に読む

func Compare(a, b string) int {

関数宣言です。funcがキーワード、Compareが関数名、(a, b string)は引数a, bが両方string型であることを示します（同じ型が続くときはまとめて最後に1回だけ書けます）。戻り値はint型ひとつ。コメントにある通り「aがbより小さければ-1、大きければ+1、同じなら0を返す」という、ソート処理でよく使われる比較関数の型（コンパレータ）です。

an, bn := Normalize(a), Normalize(b)

:=は「型を書かずに変数を宣言して値を代入する」短縮記法です。右辺でNormalize(a)とNormalize(b)という2つの関数呼び出しの結果を、左辺のan, bnにそれぞれ対応させて同時代入しています。Normalizeは別の関数で、先頭の"v"やビルド番号などの飾りを取り除く処理です（このファイルの前半に定義があります）。

if an == bn {
		return 0
	}

正規化した文字列同士が完全に一致すれば、それ以上の処理をせずに即座にreturn 0で抜けます。こうした「早期リターン」は、本題（数値部分の比較）に入る前に簡単なケースを先に片付けておく、Goでよく見るパターンです。

aNum, aPre, aOK := split(an)
	bNum, bPre, bOK := split(bn)

Goの関数はタプルのように複数の値を一度に返せます。split(an)は下で定義されているsplit関数を呼び、「数値部分のスライス」「プレリリース文字列（例: rc.1）」「パースに成功したかどうかのbool」の3つを返します。それを3つの変数aNum, aPre, aOKに一度に受け取っています。

switch {
	case !aOK && !bOK:
		return strings.Compare(an, bn)
	case !aOK:
		return -1
	case !bOK:
		return 1
	}

switchの直後に条件式がなく{}がいきなり始まっています。これはif-else ifの連鎖と同じ意味で、各caseに書いた真偽値の式を上から順に評価し、最初にtrueになったcaseだけを実行します。!はbool値を反転させる否定演算子で、!aOKは「aOKがfalseなら」という意味。つまり「aもbもパース失敗」「aだけ失敗」「bだけ失敗」の3パターンを順に判定しています。

if c := compareNums(aNum, bNum); c != 0 {
		return c
	}

ifの中に「;」で区切られた2つの部分があります。前半のc := compareNums(aNum, bNum)はif専用のローカル変数cを宣言してcompareNumsの結果を代入する初期化文、後半のc != 0が実際の条件式です。このcはif文のブロック内でしか使えません。数値部分の比較結果が0でなければ（＝優劣がつけば）そのまま返し、同じならこの下の行に処理が進みます。

return comparePre(aPre, bPre)

数値部分が完全に同じだった場合、最後にプレリリース文字列（rc.1など）同士を比較する関数comparePreに処理を委ね、その戻り値をそのままCompareの戻り値として返しています。関数の最後の処理を別関数の呼び出し結果にそのまま委譲する、よくある書き方です。

func split(v string) (nums []int, pre string, ok bool) {

戻り値の()の中に型だけでなく名前（nums, pre, ok）まで書かれています。これは「名前付き戻り値」という機能で、関数本体の中でnums, pre, okという変数がすでに宣言されているかのように使えます。[]intはint型の要素を持つスライス（可変長配列のようなもの）です。

if i := strings.IndexByte(v, '-'); i >= 0 {
		head, pre = v[:i], v[i+1:]
	}

strings.IndexByte(v, '-')は文字列vの中からハイフンを探し、見つかった位置（インデックス）を返します。見つからなければ-1です。i >= 0で「見つかった場合」を判定し、v[:i]（先頭からi文字目の手前まで）とv[i+1:]（i+1文字目から末尾まで）というスライス構文で、ハイフンの前後を切り分けています。例えば"1.4.0-rc.1"なら、head="1.4.0"、pre="rc.1"になります。

for _, p := range strings.Split(head, ".") {

strings.Split(head, ".")は文字列headをピリオドで分割し、文字列のスライスを作ります。range はスライスを先頭から順に走査するためのキーワードで、本来は「インデックス, 値」の2つを返しますが、インデックスが不要なのでアンダースコア_で明示的に捨て、値だけをpで受け取っています。

n, err := strconv.Atoi(p)
		if err != nil || n < 0 {
			return nil, "", false
		}

strconv.Atoi(p)は文字列pを整数に変換しようとする関数で、「変換結果」と「エラー（失敗していればnilではない値）」の2つを返します。Goには例外機構がなく、こうして戻り値のerrを毎回if err != nilでチェックするのが基本の作法です。ここでは変換失敗（err != nil）または負の数（n < 0）なら、パース失敗を表す(nil, "", false)を即座に返しています。

nums = append(nums, n)

append(スライス, 追加する値)は、スライスの末尾に値を加えた新しいスライスを返す組み込み関数です。forループが1周するたびにnに変換後の数値が入り、それをnumsの末尾に積み上げていくことで、"1.4.0"のようなドット区切りの各数字をひとつの[]intにまとめています。

return nums, pre, true

ここまでで集めたnums（数値のスライス）とpre（プレリリース文字列）、そしてパース成功を示すtrueの3つを一度に返します。名前付き戻り値なのでnums, preはそのまま使えますが、分かりやすさのためにここでは明示的に書かれています。

今日覚えて帰ること

Goの比較ロジックは「早期リターンで簡単なケースを先に処理し、switchやif-with-initで条件を段階的に絞り込み、複数の戻り値＋errチェックで失敗を表現する」という型で書くと、分岐が多くても読みやすくなる——この組み合わせを覚えて帰ってください。
